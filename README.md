\# Identifying Human Factors in Aviation Accidents



This project implements an NLP and Machine Learning approach to identify human factors in aviation accidents using accident narrative text.



\## Objective

To classify aviation accident reports into human factor categories such as Unsafe Act, Precondition, and Unsafe Supervision.



\## Dataset

The dataset is derived from aviation accident records and includes accident narratives and investigator findings.



\## Methodology

\- Text preprocessing using NLP techniques

\- Feature extraction using TF-IDF

\- Supervised classification using K-Nearest Neighbors (KNN)



\## Results

The KNN classifier achieved an accuracy of approximately 86% on the test dataset. Performance was higher for the majority class due to class imbalance.
